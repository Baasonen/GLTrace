# GLTrace
<img width="3439" height="1408" alt="image" src="https://github.com/user-attachments/assets/565f653d-d4b2-4dc0-9757-80e1d65464e4" />

***
Path tracer written in **C** using **OpenGL 4.6** with support for meshes with **SAH BVH acceleration** and a **PBR** material system.
*** 
### Build Requirements

- OpenGL 4.6
- GLFW
- SDL3
***
### Running
- Makefile included
- Scene to load given as argument (default 1.scene)

***NOTE: Vsync disabled by default to increase throughput***
***
### Controls
|Key|Action|
|:---|:---:|
|N|Sky color|
|F|Denoise|
|L|Lock camera|
|W/A/S/D|Move camera|
|Space / LCTRL|Move camera (Z)|
|Esc|Quit|
